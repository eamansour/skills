# AI agent skills

The `skills` directory contains skills for AI agents. Each skill is a self-contained folder with a `SKILL.md` and any supporting reference files that teach the agent how to work with a specific domain.

### Using all skills

To add all skills from this repo to your project using [skills.sh](https://skills.sh) (`npx skills`):

```bash
npx skills add eamansour/skills
```

### Using a single skill

To add only one skill to your project:

```bash
npx skills add eamansour/skills@dependency-update
```

### Keeping skills up to date

```bash
npx skills update
```
